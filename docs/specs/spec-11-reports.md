# Spec 11: Business & Customer Reports

## Description
Feature: Business & Customer Reports
Backend endpoints for each report:
- Day Book Report (daily transactions summary)
- Invoice Report (filterable by date/status/payment)
- Spares Consumption Report
- Technician Productivity Report (TAT analysis)
- GST Filing Report (GSTR-1 format)
- Vendor Purchase Report
- Customer Source Report
- Stock In/Out Report
Frontend:
- Report listing page
- Date range + filter controls per report
- Table view with pagination
- Export to Excel/CSV/PDF per report
